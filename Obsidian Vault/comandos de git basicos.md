Sin `git-flow`, usa Git puro:

### Crear nueva rama:

```bash
git checkout -b nombre-de-la-rama
```

Ejemplo:

```bash
git checkout -b feature/login
```

### Para cambiar de rama:

```bash
git checkout nombre-de-la-rama
```

### Para ver ramas:

```bash
git branch
```

### Para borrar una rama:

```bash
git branch -d nombre-de-la-rama
```
