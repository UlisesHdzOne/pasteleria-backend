## para documentar el codigo en los dto y controladore de prisma y nest
El DTO con @ApiProperty de @nestjs/swagger se usa para documentar la API y generar la documentación Swagger/OpenAPI.

Sí, para usar `@nestjs/swagger` debes instalarlo junto con `swagger-ui-express`:

```bash
npm install @nestjs/swagger swagger-ui-express
```

Luego configuras Swagger en tu `main.ts` para generar la documentación automáticamente. ¿Quieres que te ayude con eso?
